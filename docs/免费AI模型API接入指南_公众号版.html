十、傀儡编排玩法（我的理念）

日常聊天只是这些 API 的入门用法。真正的高性价比用法是收编成傀儡——让稳定的接口专职干四类基础活：

基础活 干什么
分类 一段文本属于哪个类别（财经/科技/电商…），或判断搜索结果是否相关
打标 从文本里提取 3-5 个关键词标签
摘要 长文压缩成几句话
改写 换风格重写（口语化/正式/轻松）

四个稳定接口 = 四个同时干活的傀儡（如 agnes-2.5 / agnes-2.0 / glm-4-flash / 讯飞 lite 并行处理不同任务）。免费接口变动快（可能突然收费或断线），建议收编前实测、并定期体检可用性——稳定性才是选接口的第一标准。

🎯 为什么这么干（傀儡编排的底层逻辑）

这不是随便堆几个免费接口，而是一套有讲究的编排：
· 中央编排者：你（或主模型）是总指挥，只分派任务、不亲自干苦力，把四类基础活全甩给傀儡。
· 异构傀儡池：每个傀儡特长不同（agnes-2.5 推理强、glm-4-flash 交叉验证、agnes-2.0 打标摘要快、lite 兜底便宜），按活儿挑人，不指望一个接口包打天下。
· 三层兜底（级联）：主力傀儡挂了→换备胎→再不行主模型亲自上。免费接口随时可能崩，级联保证任务不卡死。
· 一致性即置信度：同一道题让两个傀儡各做一遍，答案一致就放心用，不一致就当存疑——用"交叉验证"替代"盲信单个模型"。
说白了：用一群便宜但不稳定的傀儡 + 一套兜底规则，换一个永远不掉链子的稳定产出。

🔬 不是拍脑袋：这套理念被前沿研究独立验证过

我把"傀儡"命名拿去做学术检索，发现它和 2025-2026 年 AI 工程的前沿方向同构——学术圈叫「Puppeteer Pattern」（木偶师范式，NeurIPS 2025）：中央编排者动态指挥一群专用傀儡，而不是一个通用大模型干所有事。更关键的是，我的几个核心设计被研究系统性验证过：
· 异构傀儡池（四傀儡分工）：对应学术的「专用傀儡分工」——方向完全正确，不是我自嗨。
· 双模型交叉一致→高置信：学术证实「一致性检查」是最可靠的置信度信号之一，比模型自己说"我有信心"靠谱得多。
· 三层兜底（级联）：就是学术「Cascading 级联」的工程落地——先小模型试，不行再升级，成本控制有据可循。
· 成本门控（按档位开傀儡）：对应学术「成本感知奖励」的显式规则版。
· 2 傀儡并行不贪多：学术证实 2-3 个聚焦 worker 优于 10 个并行（上下文争用 + 协调开销，多不一定好）——我的克制是对的。
所以这不是"找免费模型凑合用"，而是一套被独立研究背书过的工程哲学：用编排和兜底，把一群不稳定的廉价资源，驯化成稳定可靠的产出管道。

维度 内容 + 为什么根本

十三、仲裁的进化：为什么裁判不能让模型家族内部产生

这套体系跑了一周后，被一项研究打脸了。

我的用法是：重要判断让两个不同模型交叉验证，不一致时让第三个模型当裁判。听起来很稳——直到读到 LLM-as-Judge 的研究：裁判模型会给自己同家族的输出系统性加 5%~25% 的分（自偏好偏差）；裁判还有位置偏差，先出现的答案天然占优 10~15 个百分点，而且这种偏差长在模型的解码机制里，写提示词求它"公平公正"基本没用。

自查了一下：我的裁判恰好和其中一位选手同源——而且不止一处。两个"看起来很稳"的仲裁安排，都是同族裁判。

修正方案想了三层：换异族裁判？可以，但裁判能力天花板摆在那。双序各跑一遍？偏差压下去了，成本翻倍。最后选了最简单的：撤掉傀儡裁判，仲裁这件事回归主模型——主模型看两个答案和原文，直接判断哪个对，而不是做"A 还是 B"的选择题。判断权本来就该在主模型手里，仲裁也是判断。

顺带的收获：给每个任务写"验收标准"
另一个框架的实践启发了我：给 AI 的任务必须写清"什么样的输出算合格"，写模糊，AI 就交"差不多的东西"糊弄。我给每类任务补了验收标准——分类必须逐行对应、打标不许出现乱码、摘要不许丢关键事实。傀儡返回后对照着扫一眼，"感觉好像不太对"就变成了"对照验收，第 2 条不符"。判断有了锚点，模糊地带就消失了。

这一轮迭代沉淀下来一句话：能写死的规则写死（切换路径、数量阈值、验收标准），需要理解的判断放权（选谁干活、结果可不可信、最终结论）。分层不是官僚，是稳定性的来源——写死的部分不依赖模型发挥，放权的部分才值得动用最贵的注意力。
