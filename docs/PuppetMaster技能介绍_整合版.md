## 一、这是什么：把免费模型收编为数字傀儡

PuppetMaster 是一个**多智能体编排技能**——把多个免费/高性价比模型收编为"子代理傀儡"，由主模型（你正在用的旗舰模型）统一指挥，干分类、打标、摘要、翻译、解释等基础活。

**为什么不用对话窗口直接调**：主流 agent 框架的请求体动辄数百 KB（完整系统提示 + 全部工具定义），小窗口模型装不下，大请求体还会触发上游限流。绕开对话窗口、用脚本发轻量请求，才是它们的正确打开方式。

**傀儡观（一句话）**：找的不是"免费模型"，是"干基础活、稳定可支配的傀儡"——**免费只是福利，稳定才是命**。收编前必须体检，非真免费（消耗魔粒/限时额度）的模型一律不收。当前池内是一组异构的、全部真免费的模型，各司其职、定期体检防失效。

## 二、学术同构：我起的"傀儡"撞上了 2025-2026 学术前沿

Puppeteer Pattern（木偶师范式）是 NeurIPS 2025 论文（arXiv 2505.19591）正式提出的多智能体编排范式——中央编排者动态指挥一群专用傀儡，而不是一个通用大模型干所有事。PuppetMaster 的设计与它**同构**，而且已经被学术研究系统性验证了多个关键设计：

| PuppetMaster 的设计 | 对应学术范式 | 状态 |
|------------------|------------|:---:|
| 异构傀儡池（主判/交叉/打标/兜底） | Puppeteer Pattern 的「异构傀儡池」 | ✅ 验证 |
| 分类双模型交叉（一致→高置信） | Uncertainty-Based Routing 的「一致性检查」 | ✅ 验证（一致性是最可靠的置信信号，不是模型自报的"我很确定"） |
| 三层兜底（主链路→补位→主模型） | Cascading（级联） | ✅ 验证 |
| 成本门控（按档位选傀儡） | 成本感知奖励 `r−λ·C` | ✅ 验证 |
| 2 傀儡并行不贪多 | 2-3 聚焦 worker 优于 10 并行 | ✅ 验证 |
| 难度感知前置路由 | Difficulty-Aware Routing（成本降 60% 质量仅差 1 分） | ✅ 已落地 |
| Judge 仲裁位 | LLM-as-a-Judge | ✅ 已落地 |

**范式本尊还在进化**：Evolving Orchestration 把编排从静态拓扑变成可学习的序列决策（REINFORCE，实证 token −50%、调用数 −43%），拓扑从链式收敛为环形验证结构。PuppetMaster 已吸收前半段（难度路由），后半段（学习式多步调度）是下一个增量——落地的原料正是本文「五」里的调度档案。

## 三、怎么做：五步编排 + 四类基础活

**核心逻辑**：主模型负责"理解 + 判断"，傀儡负责"执行 + 加工"。命令决定「干什么」，模型决定「谁来干」——读手册的是主模型，它理解需求、按傀儡长处分派、收集结果、做判断、输出结论；傀儡只执行、不判断、不决策。

**五步编排流程**：
```
① 理解需求   主模型读任务，判断该派什么类型的活
   ↓
② 分派任务   按傀儡长处分配，难度评估给出路由建议
   ↓
③ 傀儡干活   并行派活，傀儡只执行不判断
   ↓
④ 收集判断   交叉验证 / 第三傀儡仲裁 / 兜底
   ↓
⑤ 输出结论   不足回②重新分派，足够则主模型输出最终结论
```

**傀儡干的是四类基础活**：
- **判断类**：分类、难度路由、仲裁——把"该往哪走"先筛一遍
- **加工类**：摘要、打标、改写、翻译——把长材料压成主模型能一口吞的精华
- **理解类**：解释、利弊、提取——把零散信息结构化，不占主模型上下文
- **管理类**：看池、体检、调度评分——让傀儡池自己知道谁还活着、谁干哪类最稳

**判断权红线（不可逾越）**：判断、决策、最终结论永远属于主模型。傀儡输出只是参考素材——可交叉、可仲裁、可兜底，但绝不替代主模型判断。输出密集型产出（翻译/解释/提取等）一律主模型校验后采纳，不直接引用。

## 四、范式研究精华（三份简报的浓缩）

> 以下三段由傀儡 summarize 加工、主模型校准去重。

**① Puppeteer 范式研究（Ver1.0 → Ver2.0 整合）**
学术验证 PuppetMaster 方向正确，并提示三个升级点：难度路由（简单任务走轻量模型，成本降 60%）、Judge 仲裁位（第三傀儡当裁判，主模型降级为最终兜底）、不确定性量化（一致性评分替代二元判断）。前两点已在 PuppetMaster 落地。整合版新增"调度所精确定义"——主模型是木偶师、调度所是被动承载的军火库，分派权 100% 在主模型侧；调度数据留档方案把"人工口诀"进化为"实证调度表"；并针对长列表分类输出截断给出四层规避（分批纪律 / 角色修正 / 输出预算预检 / 截断检测）。

**② 傀儡范式与 A2A 新进展（Ver1.0）**
学术侧出现可学习的动态编排（Evolving Orchestration，token −50%、调用 −43%）；工业侧形成 MCP（工具）/ A2A（协作）/ Agent Plugins（分发）三层协议栈分化。A2A v1.0 虽已发布（Protobuf + Agent Card + Task 生命周期 + mTLS/OAuth2），但实现仍混乱，judge 仲裁采谨慎派——**挂观察，不预先接入**。落地建议：编排护栏薄包装、调度序列留档立即可做；支付协议（AP2/x402）和拍卖式路由与本体系场景无关或规模不足，不采纳。

**③ 扬长避短（新踩坑的根因）**
长列表批量分类时，某傀儡输出配额不足导致静默截断——根因是"长输入 × 长输出"超出输出预算，不是网络问题。四层规避已落地：单批交叉 ≤20 行、长列表改由其他傀儡承担、输出预算预检告警、截断检测响亮失败（禁止静默截断）。

## 五、实测与决策：省 token 只是副产品

**核心灵魂**：省 token 只是第 1 维，真正的价值是**释放主模型的注意力**——让多个模型当并行手脚，主模型只读加工后的精华、只做判断。

### 5.1 省 token 实测（真实计费口径，8 类任务）
对比「主模型直读原文」vs「傀儡加工后主模型只读结果」：

| 任务类型 | 省 total | 说明 |
|---------|:---:|------|
| 输入密集（分类/打标/路由/摘要） | **78%** | 真省 token 的活，输入输出双省 |
| 输出密集（翻译/利弊/解释/提取） | **40%** | 省的是主模型生成，prompt 倒挂是预期 |
| 全类型均值 | **64%** | 短文本（<100 字）不加工——成本 > 收益 |

### 5.2 六维增量价值（为什么根本）
| 维度 | 为什么根本 |
|------|-----------|
| ① 省 token | 省的是"量"与"窗口"，防限流、防上下文爆 |
| ② 并行干活 | 多傀儡 = 多子代理同时跑，主模型不排队 |
| ③ 主模型专注度 | 只读精华，不被官网导航式噪音稀释注意力 |
| ④ 防限流 | 各 API 独立窗口互不挤占 |
| ⑤ 窗口容量 | 加工后省窗口，长会话不爆上下文 |
| ⑥ 异构视角 | 多模型交叉 + 仲裁，防单模型偏见 |

> **一句话**：傀儡池的本质是"注意力解放器 + 并行手脚"，不是省钱工具。

### 5.3 编程类实测与决策（关键边界）
实测"主模型直写"vs"傀儡写 + 主模型校验"在编程任务上的 token 成本——**必须用真实主模型当基线**（免费傀儡当基线会系统性低估主模型生成成本，得出错误结论）。结论：
- 短任务（排序/爬虫/小函数）无论主模型是谁都倒挂——绕路成本 > 省幅
- 长代码任务主模型生成预算吃紧时，傀儡可真省（实测 +23.5%），但**用户决策**：未来只要涉及代码（写/改/修 bug/加功能）一律主模型直写，傀儡池不碰代码——代码质量可控优先于省 token。

### 5.4 自我进化：调度档案
每次干活自动记录（谁干的、花了多久、成没成），任务收尾主模型补质量分——攒够样本量后聚合复盘：哪个傀儡干哪类最稳、难度路由准不准、成本分布如何，**用数据替代口诀**。这正是 Evolving Orchestration 训练信号思想的落地：让编排从"人工经验"走向"实证调度"。

## 六、A2A 观察：尺度差异，不是替代

A2A 协议（Google 2026）给所有 AI 建一条标准协作通道，让不同系统互通——与 PuppetMaster 是**尺度差异不是替代**：机内子进程范式（PuppetMaster）vs 机间智能体范式（A2A）。无机间协作需求前不预先接入，挂观察。协议栈三层分化（MCP 管工具 / A2A 管协作 / Agent Plugins 管分发）的趋势判断也呼应了"能力应设计成可携可安装的技能资产"——这正是 PuppetMaster 作为技能沉淀的方向。

## 七、选型指南要点（稳定性优先）

> 完整平台实测与配置见源文件《免费AI模型API接入指南_傀儡池.md》，此处只留结论。

- **免费 ≠ 可用，便宜 ≠ 划算**：免费但慢/不稳 = 不可用。稳定性优先于价格。
- **已收编傀儡的原则**：全部真免费、定期体检、异构互补（长文主力 / 分类主判 / 快速打标 / 短文本高频 / 多模型交叉）。
- **只收真免费**：消耗魔粒/限时额度的模型不收编（曾收编又移出的 qwen 系、魔搭系已备份，需要时按附录恢复）。
- **高性价比付费档**：DeepSeek 类按量计费是当前性价比标杆，适合当主模型或关键判断的补充。
